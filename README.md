# SE3002 – Software Quality Engineering Assignment 3

## Project Overview
This repository contains the Software Quality Engineering Assignment 3 for the SE3002 course. It focuses on testing a Student Management System using different software testing techniques and tools.

## Application Overview
The Student Management System is a web-based application developed using Python Flask. It allows users to manage student records.

## Main Features
- View student records.
- Add new students.
- Search for students.
- Edit existing student information.
- Delete student records.
- Validate student input.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Selenium WebDriver
- Postman
- Apache JMeter
- Git and GitHub
